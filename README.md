# Kin Kin Paint & Hardware Store website

Responsive static website built with plain HTML, CSS and JavaScript for GitHub Pages.

## Project files
- `index.html` — tabbed website, product catalogue, story and contact sections
- `style.css` — responsive styling
- `script.js` — tabs, English/Hindi language switch, product search/filtering, WhatsApp enquiry links
- `assets/kin-kin-logo.jpeg` — logo supplied by the business owner
- `assets/store-signboard.jpeg`, `assets/storefront-rack.jpeg`, `assets/steel-rack.jpeg`, `assets/store-detail-wood-finish.jpeg`, `assets/store-detail-planter.jpeg` — real store/product photos supplied by the owner

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish to GitHub Pages
1. Create a repository such as `kinkin-website`.
2. Upload the contents of this folder to the repository root (keep the `assets` folder).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish.

## Domain
Once you buy a domain, add it in **Settings → Pages → Custom domain**, then configure DNS using GitHub's official instructions:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
