# Kin Kin Paint & Hardware Store website

Responsive static website built with plain HTML, CSS and JavaScript for GitHub Pages.

## Project files
- `index.html` — tabbed website, product catalogue, story and contact sections
- `style.css` — responsive styling
- `script.js` — tabs, English/Hindi language switch, product search/filtering, WhatsApp enquiry links
- `assets/kin-kin-logo.jpeg` — logo supplied by the business owner

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish to GitHub Pages
1. Create a repository such as `kinkin-website`.
2. Upload the contents of this folder to the repository root (keep the `assets` folder).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish.

## Domain
Once you buy a domain, add it in **Settings → Pages → Custom domain**, then configure DNS using GitHub's official instructions:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site

## Important checks before launch
- Confirm address, phone and WhatsApp number.
- The supplied logo is used in the header, story section and footer.
- The logo says “Since 1993”; the history section only uses that supported date and does not invent older milestones.
- Product images are illustrative images sourced from public websites, not representations of confirmed in-store stock. Check the source sites' usage rights before commercial publication; ideally replace with your own store/product photographs.
- Product availability, brands, prices and opening hours are not claimed as verified.
- The catalogue lists wood-finishing materials and fittings used in furniture-making; the business is not presented as a finished-furniture retailer.
- Hindi translations cover the main interface, catalogue descriptions and business story. Product tags and some standard technical terms remain in common trade English where commonly used.
- Update all `919999505851` WhatsApp links and the `tel:` number if the store number changes.
